Draft 09 · 後台外框改版

把後台從「寬得發慌」改成「一眼看得完」

四個問題一起解：太寬太空曠、字太小對比不夠、白底刺眼、層次不清楚。動的是外框與尺度，不是重畫一套設計——方案 B 的圓角、陰影、鼠尾草綠全部保留。

01

現在 vs 改版

白話說明

  • 內容加寬度上限 1080px 並靠左。現在在寬螢幕上，三張卡被拉成 1600px 寬，讀一行字眼睛要橫向跑很遠。
  • 三張統計卡併成一張、用細線分隔。三個獨立色塊各自搶注意力，合成一張反而安靜，也省下一半高度。
  • 字級全面上調一級：標籤 11 → 11.5–12.5px、說明文 13 → 12.5–14px，並把大量的最淡灰（ink-4）換成中灰（ink-3 / ink-2）。
  • 側欄目前所在的頁面要看得出來：底色 + 左側色條 + 加粗。現在全部長一樣，你不知道自己在哪。
  • 頂部做成真的工具列，有底色與分隔線，不再是兩顆藥丸浮在右上角。
  • 空狀態不再佔掉半個螢幕：改成一條橫向卡片，右邊直接給「新增預約」的入口。

02

深色模式與亮度開關

白話說明

  • 深色代幣其實早就寫好了，只是綁在「跟隨系統」。你的系統是淺色，所以永遠看到白底。
  • 改成右上角自己切：自動 / 淺 / 深。選了就記住（存 cookie），換裝置也不會跳回去。
  • 淺色也一起調柔：頁面底色從 #f7f7f5 → #f2f3f0，卡片從純白 #ffffff → #fbfbfa。純白配深字是對比最強的組合，長時間看最累。
  • 深色不是把顏色反過來就好——鼠尾草綠會變太暗，所以主色改用較亮的 #8fb8a2，這在代幣裡也已經備好了。

實際會改的數字

項目現在改成為什麼
內容最大寬度無上限1080px寬螢幕上一行掃太遠，眼睛累
統計卡三張獨立色塊一張含分隔線少兩個色塊搶注意力，高度砍半
區塊標籤11px / ink-411.5px / ink-3最淡的灰只該用在真正的附註
說明文字11–13px12.5–14px桌機上 11px 太小
側欄字級13px13.5px + 目前位置高亮看得出自己在哪一頁
頁面底色#f7f7f5#f2f3f0降一階亮度，白卡才浮得出來
卡片底色#ffffff#fbfbfa純白配深字對比最強，也最刺眼
深色模式只能跟隨系統右上角自動／淺／深代幣早就寫好了，只差一個開關

這些改動集中在 globals.css 與 後台外框，服務項目、排班、行事曆那些頁面只會跟著容器變窄與字級變大，不用逐頁重畫。
