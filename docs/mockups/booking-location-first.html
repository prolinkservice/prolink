先選地點，

2

一個要先說清楚的代價

先選地點會失去什麼

現在的做法有一個好處：客人一眼就看得到「另一間今天有更早的時段」。 改成先選地點之後，他進了五甲、發現最早只有 19:00， 不會知道六合其實 15:00 就有——除非他退回去換一間。

以你的情況（兩間固定店面、客人通常住哪邊就去哪邊）這個代價很小， 而且不知道地址根本決定不了要去哪。所以我認為你的判斷是對的。

✅ 補救方式：地點卡片上直接寫「今天還有 N 個時段」， 甚至寫「最近可約：今天 15:00」。客人在選之前就比得出來，代價幾乎歸零。 這是第 3 節的第 1 題。
📌 規格書 §9.5 原本寫的是「先選時間，再選地點」，理由是老師到處跑、時段本來就綁著地點。 那是為純到府／多點流動的職人寫的。你是兩間固定店面，情況不同，這次改動只影響有據點的服務。
3

要你決定的三件事

1地點卡片上要顯示什麼？

這決定客人在「還沒點進去」的時候能不能比較兩間。

建議名稱 + 地址 + 「今天還有 N 個時段」。看得出哪一間比較空，快滿的那間還會變成橘色提醒。
再加一行「最近可約：今天 15:00」。比較力最強，但今天沒空檔時要顯示「最近 8/4（二）10:00」，字會變長。
只有名稱和地址。最乾淨，但客人得一間一間點進去才知道有沒有位。
2只有一間店的職人，要不要也多點一次？

大部分職人只有一個據點。多一個只有一張卡片的畫面，是純粹的多按一下。

建議只有一個據點就自動跳過，直接進時段。他們的流程完全不變，步驟仍然顯示 1／2。
一律都要選。流程統一好解釋，但單店客人會覺得「幹嘛叫我選一個沒得選的東西」。
3到府服務怎麼辦？

到府沒有據點，客人填的是自己家的地址。你目前沒有到府服務，但之後可能會加。

建議到府服務跳過選地點，直接進時段。地址在最後填資料那一步問，跟現在一樣。
先問「到店還是到府」。之後真的做到府服務再說，現在做等於憑空想像。
