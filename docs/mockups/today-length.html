三版的取捨

A
現況：資訊最完整，但太長

每筆都能看到全部細節，不用點開。代價是 8 筆就要捲 2.6 屏，在外面單手滑很累，而且「現在該做什麼」被埋在中間。

B
收合瘦身：長度砍一半，習慣不變

已完成的收成一行，每筆瘦成一行。關鍵是狀態標籤只在「有事」時才出現——定金已付就不顯示，沒消息就是好消息。改動小，風險低。

C
下一筆大卡：一屏搞定，但要多點一下

老師在外面其實只想知道「下一個是誰、幾點、在哪、怎麼去」。把那件事放到最大，其餘壓成一行。要看細節就點開。

＋
三版共用的兩個修正

①頂部三個數字改成一條細橫排，省下 70px。②打開時自動捲到現在的時間，已完成的自然在視線之外。

我的建議：C 當預設，B 當備案

到府與多據點的老師一天在外面看這頁十幾次，他每次要的答案都是同一個：「下一個去哪」。C 把那個答案放到最大、還附導航與出發時間，一屏就解決。而坐在店裡的老師比較想看整天的排程，那種情況 B 比較合適——所以右上角給一個切換鈕，讓老師自己選要哪種檢視，記住他的選擇。
