機器人住進你們現在的 LINE 群
教練照原本的方式打字就好

不做新的 App，不叫教練改習慣。把助理每天在做的「查有沒有撞期」和月底在做的「翻對話算時數」交給系統，其他一切照舊。

01

群組裡的預約流程

機器人被邀請進「六合健身房 · 教練群」，看得到群裡的訊息，也能在群裡回話。

白話說明

  1. 王教練照舊在群裡打：「8/2 19:00-20:00 預約空間」。
  2. 機器人當下就查那個時段有沒有被別人租走，把結果貼回群裡。
  3. 沒撞期 → 出一張卡等老闆或助理按「確認」。只有管理員按得動，教練自己按沒有反應。
  4. 撞期了 → 機器人直接說「這個時段李教練已經租了」，並列出最近的空檔。助理根本不用回這則訊息。
  5. 確認之後，系統自動記下這一小時，月底直接產出每位教練的使用時數與金額。
老闆可以開「自動確認」：只要沒撞期就自動通過，助理完全不用盯群組。撞期或超時的才需要人工處理。

02

老闆後台看到什麼

群組裡發生的每一件事，都會落在後台。老闆不用進群也知道場地租到什麼程度。

白話說明

  1. 一張表看完整週，哪個時段被誰租走一目了然，不用再翻 LINE 對話記錄。
  2. 藍色是還在等確認的，點一下就能直接核准，不必回群組。
  3. 月底自動出對帳單：每位教練用了幾小時、該收多少錢，不用再自己算。
  4. 對帳單可以直接發到群組裡，或單獨發給每位教練。

03

助理的工作變成什麼樣

這才是這套系統真正的價值——教練的習慣完全沒變，變的是助理不用再靠腦袋記事情。

現在人工

  • 教練在群裡說要借場地
  • 助理翻對話記錄確認有沒有撞期
  • 助理回「OK」，但這則訊息很快被洗掉
  • 有人記錯就會兩組人同時到場
  • 月底翻整個月的 LINE 算每個教練用幾小時
  • 教練對金額有疑問，只能再翻一次

用了系統自動

  • 教練在群裡說要借場地 （完全沒變）
  • 機器人立刻查，撞期直接擋掉並給空檔
  • 確認紀錄永久保存，隨時查得到
  • 資料庫層擋重複，不可能兩組人撞在一起
  • 月底自動出對帳單，一鍵發到群組
  • 每筆都有時間與確認人，有疑問直接調紀錄
1
機器人要先被邀請進群，而且官方帳號要開啟「允許加入群組」

這是 LINE 的設定，導入時要幫老闆設一次。設完之後就一直有效。

2
誰能按「確認」要先綁定

老闆在後台產生一組綁定碼，在群裡輸入一次，系統就知道誰是管理員。其他人按沒反應。

3
看不懂的訊息一律不動作

群裡大家會閒聊，機器人只對「有日期＋有時間」的訊息反應，其他一概安靜，不要洗版。

4
取消也要能在群裡講

「8/2 那場我不借了」要能取消，並且自動把時段釋出、通知在等的人。
