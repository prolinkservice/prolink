01

老師在 LINE 打一句話，預約就進系統

老師端

白話說明

  1. 老師接到電話，客人說「8/2 晚上七點想約」。
  2. 老師不用開後台，直接在 LINE 跟系統說一句：「8/2 晚上7點 六合健身房 陳小姐 推拿90分」。
  3. 系統把這句話拆成一張卡：日期、時間、地點、客人、服務，並且順便檢查那個時段有沒有撞到別的預約。
  4. 沒抓到的欄位（例如電話）會用紅字標出來，老師可以直接補，也可以先跳過。
  5. 老師按「確認建立」，預約就出現在後台行事曆，客人也會收到 LINE 通知。

重點：系統永遠不會自己直接建立，一定先出卡片給老師確認。聽錯一個字就開錯單，比多按一下嚴重得多。

這個功能的三個關鍵決定

01
永遠先出確認卡，不直接建單

語意理解一定會有誤判，多按一次「確認」換來零開錯單，划算。

02
看不懂就問，不要猜

缺日期或缺時間就直接反問「請問是幾號？」，不要自作聰明填預設值。

03
地點與服務要對得上老師自己的設定

「六合健身房」要能對到他建立的據點，「推拿90分」要對到他的服務項目。對不到就列出清單讓他點選。

02

客人在 LINE 看時段，點一下就約好

客人端

白話說明

  1. 客人加了老師的 LINE 官方帳號，下面有一排圖文選單，按「我要預約」。
  2. 系統直接把老師接下來還沒被約走的時段列出來，像時刻表一樣。
  3. 灰掉的是已經滿了；亮的是可以約。點一下就進到確認畫面。
  4. 確認畫面填名字和電話（老客人自動帶入），需要付定金的話在這裡付。
  5. 約好之後，前一天晚上和當天出發前，系統各發一次提醒。

全程不用註冊、不用下載 App、不用記帳號密碼。客人只是在跟老師的 LINE 講話。

這個功能的三個關鍵決定

01
只列「真的可以約」的時段

已經被約走的、老師不在那個據點的、來不及移動的，通通不出現。看到就能約，不會白按。

02
先選時間，再選地點

老師到處跑，時段本來就綁著地點。硬要客人先選地點反而多一步。

03
提醒訊息裡一定要有「取消」按鈕

取消愈好按，放鳥愈少。客人臨時不能來，讓他能一鍵告訴你，時段才救得回來。
