Draft 12 · Sprint 2

接上你自己的
LINE 官方帳號

客人加的是你的官方帳號，不是我們的。預約確認、行前提醒都用你的名義發， 客人回訊息也是回給你。這條做完，你才不用自己盯著時間提醒客人。

01

你要先去 LINE 拿三樣東西

白話說明

  • 如果你已經有官方帳號（客人已經在加的那個），直接用它，不用另外開。
  • 要到 LINE Developers 幫那個官方帳號開一個 Messaging API channel——這是讓程式能用你的名義發訊息的門。
  • 拿到之後貼三個值進來就好。貼完之後你不會再看到完整的內容，只會看到末四碼。
申請不需要公司行號，個人也可以。整個流程大約十分鐘。
1
到 developers.line.biz 建 Provider

如果你已經有，跳過。Provider 就是「誰擁有這些帳號」。

2
建立 Messaging API channel，綁到你現有的官方帳號

不要新開一個官方帳號，不然客人加的還是舊的那個。

3
複製 Channel ID 與 Channel secret

在 Basic settings 那一頁。

4
發一組 Channel access token

在 Messaging API 那一頁最下面，選長期的。

5
把 Webhook URL 貼回 LINE，並打開「Use webhook」

網址我們會產生給你，長得像 /api/line/webhook/你的編號。

02

設定畫面：貼上、驗證、複製 Webhook

白話說明

  • 貼完按「驗證並儲存」，系統會立刻拿你的 token 去問 LINE：這個帳號是誰。問得到就把官方帳號名稱顯示出來，你一眼知道有沒有貼錯。
  • 憑證加密後才進資料庫，畫面上只留末四碼。那組 token 等於「可以用你的名義發訊息給所有好友」，不能明文躺著。
  • Webhook 網址每個店家不一樣，複製貼回 LINE 後端。沒貼這一步，客人傳訊息我們收不到。
  • 驗證成功後可以按「發測試訊息給我」——你要先加自己的官方帳號好友，收到才算真的通了。

03

訊息用量看板

白話說明

  • LINE 免費方案每月 200 則推播。系統會自動發確認、提醒、回訪，很容易在月底爆量。
  • 爆量不會擋你發，是你收到 LINE 的帳單才發現——所以這個數字要一直看得到。
  • 用到 80% 會跳警告，並告訴你剩下的額度大概還能撐幾天。
  • 下面拆給你看錢花在哪：確認、提醒、取消通知各佔多少。提醒通常是大宗，覺得太多可以只留出發前那一次。
同類產品普遍沒做這個。做了就是差異化——但更重要的是，你不會被帳單嚇到。

04

客人怎麼跟他的預約對上

白話說明

  • 訊息要發給誰，靠的是 LINE 的使用者編號。問題是客人在預約頁上只留了手機號碼，兩邊要對得起來。
  • 做法：預約成功頁的「加店家 LINE」按鈕帶一個一次性的代碼。客人加好友後，我們收到 follow 事件，就把那個代碼對回他的預約，兩邊接起來。
  • 沒加好友的客人收不到任何通知——這是 LINE 的規則，不是我們的選擇。所以完成頁會把「加好友才收得到提醒」講清楚。
  • 加過一次就永久記住，之後同一個人再預約直接發得出去。
這一段是 Sprint 2 最容易出錯的地方，我會先讓它能運作、再處理各種例外（換手機、封鎖官方帳號、退追蹤）。
05

分三批做

批次內容你會感覺到什麼
第一批 憑證加密儲存、驗證連線、Webhook 收訊息、測試發送、用量看板 後台能接上你的官方帳號，按下測試會收到訊息
第二批 客人加好友時綁定、預約確認通知、取消通知 客人約完馬上收到一則確認，不用再自己傳
第三批 兩段式行前提醒（前一晚 + 出發前 2 小時）、提醒訊息附「無法前往」按鈕 不用再自己盯時間；客人要取消也變好按，放鳥會變少
